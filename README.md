# EXP-3-PROMPT-ENGINEERING-

## Aim: 
Evaluation of 2024 Prompting Tools Across Diverse AI Platforms: 
ChatGPT, Claude, Bard, Cohere Command, and Meta
Experiment:
Within a specific use case (e.g., summarizing text, answering technical questions), compare the performance, user experience, and response quality of prompting tools across these different AI platforms.

## Algorithm:

Step 1: Prompt Design

Create a standardized prompt for all AI platforms.
Example:
“Summarize the given technical passage and explain key points clearly.”

Step 2: Input Execution

Submit the same prompt to all selected AI platforms:

ChatGPT
Claude
Bard (Gemini)
Cohere Command
Meta AI
Step 3: Output Collection

Collect responses generated by each platform for analysis.

Step 4: Evaluation Criteria

Evaluate outputs based on:

Accuracy and correctness
Depth of explanation
Clarity and structure
Hallucination or errors
User experience (ease of interaction and refinement)
Step 5: Comparison Analysis

Compare outputs side-by-side to identify:

Best performance in summarization
Best reasoning quality
Most user-friendly system
Most consistent responses
Step 6: Result Derivation

Rank platforms based on overall effectiveness for the given task.
## Prompt
“Evaluate the future of Artificial Intelligence. Include discussion on Artificial General Intelligence (AGI), its possible impact on society, and key future trends in AI development. Present the answer in a clear, structured, and informative manner suitable for comparison across AI platforms.”

Claude performed best in depth and accuracy, while ChatGPT gave the most balanced and clear responses across all tasks.
Overall, performance varied by platform, with each AI showing different strengths in summarization, reasoning, and usability.
